# Story 3.2: Product Variants Management

**Status:** done

## Story

As a **Merchant**,
I want **to create product variants with different options**,
So that **customers can choose size, color, or other attributes**.

---

## Acceptance Criteria

1. **AC1 - Variant Creation:** Given a product exists, when the Merchant adds variants, then they can define variant options (e.g., Size: S, M, L), SKU per variant, individual pricing per variant (in cents), and individual inventory per variant.

2. **AC2 - Variant IDs:** ProductVariants have CUID IDs with `var_` prefix (e.g., `var_abc123xyz`), automatically generated by the prefixed IDs extension.

3. **AC3 - Tenant Scoping:** Variants are accessed only through their parent product's store context. All queries validate `storeId` via product relation.

4. **AC4 - Options Uniqueness:** No two variants can have identical option combinations within a product.

5. **AC5 - At Least One Variant:** Cannot delete the last variant of a product. Active products must have at least one variant.

6. **AC6 - SKU Generation:** If SKU not provided, auto-generate from product title + option values.

7. **AC7 - Bulk Variant Generation:** Merchant can define option types (Size: S,M,L / Color: Red,Blue) and system generates all combinations automatically.

8. **AC8 - Inline Editing:** Dashboard supports inline editable cells for price, SKU, and quantity in variants table.

9. **AC9 - Dashboard UI:** Variants section within product detail page following Digital Brutalism v2.

10. **AC10 - tRPC API:** CRUD operations via tRPC router with `products:update` permission guard.

enum WeightUnit {
  G
  KG

  LB

model ProductVariant {
  id                     String     @id @default(cuid())
  productId              String     @map("product_id")
  sku                    String?    @db.VarChar(100)
  options                Json       // [{name: "Size", value: "M"}, {name: "Color", value: "Blue"}]
  priceInCents           Int        @map("price_in_cents")

  // Indexes
  @@unique([productId, sku])
  @@index([productId])
  @@map("product_variants")

#### Backend Service Pattern (RETRO-2)
All services MUST use `protected` methods (not `private`) for @trafi/core extensibility:

```typescript
@Injectable()
export class VariantsService {
  protected readonly logger = new Logger(VariantsService.name);

  constructor(
    protected readonly prisma: PrismaService,
    protected readonly eventEmitter: EventEmitter2,
  ) {}

  // Protected for extensibility
  protected generateSku(productName: string, options: VariantOption[]): string {
    const prefix = productName.substring(0, 3).toUpperCase();
    const optionPart = options.map(o => o.value.substring(0, 2).toUpperCase()).join('-');
    const random = crypto.randomUUID().substring(0, 4).toUpperCase();
    return `${prefix}-${optionPart}-${random}`;
  }

  protected validateOptionsUnique(existingVariants: { options: unknown }[], newOptions: VariantOption[]): void {
    const sortOptions = (opts: VariantOption[]) =>
      [...opts].sort((a, b) => a.name.localeCompare(b.name));

    const newKey = JSON.stringify(sortOptions(newOptions));

    for (const variant of existingVariants) {
      const existingOpts = variant.options as VariantOption[];
      const existingKey = JSON.stringify(sortOptions(existingOpts));
      if (existingKey === newKey) {
        throw new ConflictException('A variant with these options already exists');
      }
    }
  }

  protected generateCombinations(optionTypes: { name: string; values: string[] }[]): VariantOption[][] {
    if (optionTypes.length === 0) return [];

    let combinations: VariantOption[][] = [[]];

    for (const optionType of optionTypes) {
      const newCombinations: VariantOption[][] = [];
      for (const combo of combinations) {
        for (const value of optionType.values) {
          newCombinations.push([...combo, { name: optionType.name, value }]);
        }
      }
      combinations = newCombinations;
    }

    return combinations;
  }
}
```

#### Tenant Isolation via Product (CRITICAL)
Variants don't have direct `storeId`. Isolation is via Product:

```typescript
// In VariantsService - CORRECT
async create(storeId: string, input: CreateVariantInput) {
  // Verify product belongs to store
  const product = await this.prisma.product.findFirst({
    where: {
      id: input.productId,
      storeId,
      deletedAt: null  // Exclude soft-deleted products
    },
    include: { variants: true },
  });

  if (!product) {
    throw new NotFoundException('Product not found');
  }

  this.validateOptionsUnique(product.variants, input.options);

  // Create variant - ID auto-generated by extension
  const variant = await this.prisma.productVariant.create({
    data: {
      productId: input.productId,
      sku: input.sku || this.generateSku(product.name, input.options),
      options: input.options,
      priceInCents: input.priceInCents,
      compareAtPriceInCents: input.compareAtPriceInCents,
      costPriceInCents: input.costPriceInCents,
      quantity: input.quantity,
      trackInventory: input.trackInventory,
      weight: input.weight,
      weightUnit: this.toPrismaWeightUnit(input.weightUnit),
    },
  });

  this.eventEmitter.emit('variant.created', { variant, product, storeId });
  return variant;
}

// For delete - verify tenant via product relation
async delete(storeId: string, variantId: string) {
  const variant = await this.prisma.productVariant.findUnique({
    where: { id: variantId },
    include: { product: true },
  });

  if (!variant || variant.product.storeId !== storeId) {
    throw new NotFoundException('Variant not found');
  }

  // Check at-least-one constraint
  const count = await this.prisma.productVariant.count({
    where: { productId: variant.productId },
  });

  if (count <= 1) {
    throw new BadRequestException('Cannot delete the last variant');
  }

  await this.prisma.productVariant.delete({ where: { id: variantId } });
  this.eventEmitter.emit('variant.deleted', { variant, storeId });
}
```

#### tRPC Router Pattern
```typescript
// apps/api/src/trpc/routers/variants.router.ts
import { router, protectedProcedure } from '@/trpc';
import {
  CreateVariantSchema,
  UpdateVariantSchema,
  BulkCreateVariantsSchema,
} from '@trafi/validators';
import { z } from 'zod';

export const variantsRouter = router({
  create: protectedProcedure
    .input(CreateVariantSchema)
    .mutation(async ({ input, ctx }) => {
      ctx.requirePermission('products:update');
      return ctx.services.variantsService.create(ctx.storeId!, input);
    }),

  bulkCreate: protectedProcedure
    .input(BulkCreateVariantsSchema)
    .mutation(async ({ input, ctx }) => {
      ctx.requirePermission('products:update');
      return ctx.services.variantsService.bulkCreate(ctx.storeId!, input);
    }),

  update: protectedProcedure
    .input(UpdateVariantSchema)
    .mutation(async ({ input, ctx }) => {
      ctx.requirePermission('products:update');
      return ctx.services.variantsService.update(ctx.storeId!, input);
    }),

  delete: protectedProcedure
    .input(z.object({ id: z.string() }))
    .mutation(async ({ input, ctx }) => {
      ctx.requirePermission('products:update');
      return ctx.services.variantsService.delete(ctx.storeId!, input.id);
    }),

  list: protectedProcedure
    .input(z.object({ productId: z.string() }))
    .query(async ({ input, ctx }) => {
      ctx.requirePermission('products:read');
      return ctx.services.variantsService.listByProduct(ctx.storeId!, input.productId);
    }),
});
```

### Previous Story Intelligence (from Story 3.1)

1. **Prefixed IDs via Extension:** Don't manually generate IDs. The PrismaService extension handles `var_` prefix automatically.

2. **Soft Delete Awareness:** When querying products for variant operations, always check `deletedAt: null` to exclude soft-deleted products.

3. **Protected Methods Pattern:** Use `protected` (not `private`) for all service methods that merchants might want to customize.

**ARCH-INV-1:** Reserved stock for variants is COMPUTED via SUM from InventoryReservation, not stored on variant. This affects Story 3.7/3.8.
